# Naming Convention → moved to the family hub

The ARCIS naming convention is family-level and lives in the hub:
**<https://github.com/JongoDB-Labs/arcis/blob/main/naming.md>**

Short version: the family is **ARCIS** ("of the citadel"); this repo is
**ARCIS AEGIS** (the shield — the runtime substrate). Every component name is a
nominative noun ≤4 syllables from the Roman fortification lexicon that makes
`ARCIS <NAME>` parse as real Latin.
